# Security policy

Report vulnerabilities in the current release or current staging branch. For the public repository, use **Security → Report a vulnerability**. Staging collaborators should contact a maintainer through an existing private channel.

Include the affected URL or commit, reproduction steps, the impact, and any relevant environment details. Share the minimum evidence needed to reproduce the issue. Keep exploit details and credentials out of public issues and pull requests. Use the source correction form for an inaccurate data record.

Maintainers will confirm receipt in the report, investigate, and coordinate a fix and any public advisory. If you accidentally encounter someone else's data, stop and tell the maintainers what happened without copying that data into the report.
